## 1. サービス概要
スケジュール管理

## 2. このアイデアはどこから生まれたか
スケジュール登録の際、メモを記入することがある。

色ごとにカテゴリ分けして記入するルールとしているため
月単位でカレンダーを表示した際に、おおよそのタスクを色で把握することができる。

しかし、カレンダーで「埋まっている時間」や「おおよそのタスク」が把握できるものの
タスク単位で作業を把握することができず
・同様の作業を以前行った際は何分くらい時間がかかったのか
・このタスクは間歇的に発生するが、どんなスパンで発生しているか
ということが把握できない。

## 3. 課題の整理（表面的になっていないか）
・使用可能な色を増やし、色でカテゴリがわかるようにする
・タスクの親子関係や関連情報を目視・手動検索する手間を減らす
　　・色の濃い・薄いでカテゴリの親子関係を表す　など）
　　・タグやキーワードをつけられるようにする
　　・タグやキーワードの検索機能をつける
　　・関連タスクを手動で探すのではなく、リンクにして飛べるようにする

## 4. 想定ユーザーについて
一日のなかで突然追加作業が発生することがそれなりにあり、スケジュールが変動しがちな人

## 5. 既存サービス・競合調査
IPhone　カレンダー

## 6. このサービスで提供したい価値
「打合せ」のように決まった時間を占有するものはスケジュール的に管理しやすいが
自身の能力によって作業完了時間が変動するタスクは、慣れないうちは特に
”この作業におおよそ〇分かかる”という見込みをつけることが難しい。

当日のスケジュール完了時間が想定からずれる事を少なくするため、1日にやるべきことの把握と併せて
以前そのタスクを実施した際は
・そのタスクの作業量がどれくらいだったか
・だいたい何分くらい時間がかかったか
を把握できるようにしたい。
